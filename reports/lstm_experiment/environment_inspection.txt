6. Existing LSTM preprocessing reuse assessment
-----------------------------------------------
Reusable, inspected helpers:
  src/final_validation.py::_build_sequences
    Builds only calendar-contiguous observed sequences and never imputes gaps.
  src/final_validation.py::_sequence_split
    Uses chronological 70/15/15 sequence-target ordering.
  src/final_validation.py::_lstm_fit_predict
    Fits input and target StandardScaler objects on training data only, applies
    them to validation/test data, supports validation early stopping, and
    inverse-transforms predictions before metrics.
  src/final_validation.py::_recursive_lstm_forecast
    Feeds recursive predictions back into the 12-month input window.

src/lstm_experiment.py contains a similar exploratory implementation, but its
artifact paths and report paths point at the existing market-level locations.
It should not be reused as-is for this recovery experiment because the new
models/reports must remain isolated. The lower-level sequence/scaling logic can
be adapted into a separate experiment script.

Create an isolated .venv-lstm environment with the installed 64-bit Python
